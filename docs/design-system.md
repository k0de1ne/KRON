# Дизайн-система kron

Один принцип: **квадрат**. Логотип — залитый квадрат акцентного цвета, и вся остальная графика с ним согласована: углы почти прямые, линии тонкие, декора нет. Интерфейс — инструмент, он уступает место содержимому.

## Принципы

1. **Содержимое важнее рамки.** Ответ агента, дифф и вывод команд занимают место; хром (панели, кнопки) тихий и нейтральный.
2. **Один акцент.** Акцентный цвет (`--accent`) только для главного действия, фокуса и логотипа. Статусы — отдельные `--ok`, `--warn`, `--danger`; цвет никогда не единственный носитель смысла (рядом иконка или слово).
3. **Состояние всегда видно.** Любое действие даёт отклик не позже 100 мс: нажатие, загрузка, ошибка с причиной и следующим шагом, пустое состояние с подсказкой, что делать.
4. **Мобильный — основной.** Цели нажатия ≥ 44 px на тач-экранах (`--tap`), учёт `safe-area` и экранной клавиатуры.
5. **Клавиатура — на равных.** Каждое действие доступно без мыши; фокус виден (`--focus`); меню и диалоги закрываются Esc и возвращают фокус.
6. **Русский, коротко.** Глагол в кнопке («Войти», «Отправить»), без «пожалуйста», без технических кодов в тексте для человека.

## Палитра

Холодный графит и один кобальтовый акцент — намеренно не тёплые «бумажные» тона и не терракота. Светлая тема: фон `#f5f6f8`, текст `#0f1218`, акцент `#2a47f0`. Тёмная: фон `#0e1014`, поверхности `#181b21`, акцент `#4560ff` (текст-акцент `#93a5ff`). Статусные цвета (зелёный, янтарный, красный) не связаны с акцентом.

## Токены (`src/ui/app.css`, блок `:root`)

| Группа | Токены |
|---|---|
| Поверхности | `--bg`, `--surface`, `--surface-2`, `--sidebar`, `--code` |
| Текст | `--fg`, `--fg-2`, `--muted` (все ≥ 4.5:1 на своих фонах, WCAG AA) |
| Линии | `--line`, `--line-strong` |
| Акцент и статусы | `--accent`, `--accent-text`, `--accent-soft`, `--ok`, `--warn`, `--danger` (+ `-soft`) |
| Радиусы | `--r-xs 2` · `--r-sm 4` · `--r-md 6` · `--r-lg 8` · `--r-xl 10` (полных кругов и «таблеток» нет, в том числе у переключателей и индикаторов) |
| Отступы | шаг 4 px: `--s-1 … --s-8` |
| Тени | `--shadow-1` (карточка), `--shadow-2` (меню), `--shadow-3` (диалог) |
| Движение | `--fast 120ms`, `--med 200ms`, `--ease`; при `prefers-reduced-motion` отключается |
| Шрифты | `--font` (интерфейс), `--mono` (код, пути, команды). Засечек нет |

Тёмная и светлая темы — одним набором токенов; компоненты цвета не хардкодят.

## Компоненты

- **Кнопки:** `primary` (одна на экран), обычная, `icon-btn` (только иконка + `aria-label`), опасная (красная, только с подтверждением).
- **Меню и диалоги:** `role=menu`/`dialog`, фокус внутри, Esc закрывает, фон-затемнение закрывает по клику.
- **Чипы и бейджи:** прямоугольные, 4–6 px, текст ≥ 12 px.
- **Карточки шагов агента:** свёрнуты по умолчанию, в шапке — что сделано и итог; детали раскрываются.
- **Тосты:** `aria-live=polite`, исчезают сами, ошибки не исчезают, пока их не закрыли.
- **Пустые состояния:** иконка/логотип, одна фраза, 1–3 действия.

## Логотип

Залитый квадрат на ~40% поля иконки (`#4560ff` на `#0e1014`; в интерфейсе — `--accent`); слово `kron` — `--font`, 600. Файлы: `src/assets/icon.svg`, `icon-192.png`, `icon-512.png`, Android `ic_launcher.png`, `ic_stat.xml`. Минимальный размер — 16 px.
