# Служебный режим kron

Свой интерфейс человека пишет агент (см. [face.md](face.md)). Здесь — служебный режим `/kron/app`: вход в подписки, модели, настройки и обычный чат с агентом, на случай если своего интерфейса ещё нет или он сломан. Это `src/ui/`: `index.html` (разметка и иконки), `app.css` (дизайн-система, её же используют страницы ядра), `app.js` (логика), `vendor/` (marked, DOMPurify, highlight.js). Хаб встраивает всё это в бинарник, поэтому интерфейс работает без интернета: на телефоне с локальной моделью, в самолёте, за Tailscale. Сборки нет: правите файл, `cargo build`, обновляете страницу.

## На чём основаны решения

| Принцип | Источник | Как сделано в kron |
|---|---|---|
| Видимость состояния системы | Nielsen, 10 эвристик юзабилити (№1) | Индикатор работы и вопроса в списке чатов; текущий шаг агента и таймер в заголовке группы шагов; план с прогрессом «2 из 5»; баннер «нет связи с хабом»; ● / ⏸ в заголовке вкладки |
| Контроль и свобода пользователя | Nielsen (№3) | «Стоп» всегда под рукой (кнопка и Esc); правка сообщения и «ответить заново» создают ветку, ничего не теряется; удаление с «Отменить» |
| Отмена вместо подтверждения | A. Raskin, «Never use a warning when you mean undo» (2007) | Удаление чата не спрашивает «вы уверены?», а 5 секунд можно отменить |
| Предотвращение ошибок | Nielsen (№5) | Режимы «Спрашивать» и «Только чтение»; в запросе на подтверждение показан дифф правки или команда |
| Узнавание вместо припоминания | Nielsen (№6) | Палитра команд (Ctrl+K) с поиском по действиям и чатам; подсказки клавиш; меню моделей с поиском и группами |
| Гибкость для опытных | Nielsen (№7) | Горячие клавиши (Ctrl+K, Ctrl+Shift+O, Ctrl+B, Ctrl+Shift+E, ↑ для правки, /), другая модель провайдера прямо в меню |
| Закон Хика | Hick, 1952; Hyman, 1953 | Выбор модели разбит на группы (подписки, на устройстве, API, агенты, веб-чаты); редкие настройки убраны в «Настройки» |
| Закон Фиттса, размер целей | Fitts, 1954; WCAG 2.2, 2.5.5 и 2.5.8; Apple HIG (44 pt); Material (48 dp) | На сенсорных экранах все кнопки и пункты меню не меньше 44 px; кнопка отправки крупная и в углу, куда тянется большой палец |
| Порог Доэрти (ответ быстрее 400 мс) | Doherty & Thadani, IBM, 1982 | Сообщение появляется сразу; ответ стримится кадр за кадром; удаление чата не ждёт сервера |
| Прогрессивное раскрытие | Nielsen Norman Group | Шаги агента — по строке на шаг, подробности (вывод, дифф) по нажатию; длинные группы сворачиваются после ответа; размышления свёрнуты |
| Длина строки 50–75 знаков | Bringhurst, «The Elements of Typographic Style»; Baymard Institute | Колонка текста ≤ 760 px при кегле 16 px; межстрочный интервал 1.7 для ответов |
| Контраст | WCAG 2.2 AA, 1.4.3 и 1.4.11 | Все цвета текста ≥ 4.5:1 к фону в обеих темах (проверено расчётом), иконки ≥ 3:1; акцент затемнён до #b5512f ради контраста |
| Видимый фокус | WCAG 2.2, 2.4.7 и 2.4.11 | Кольцо фокуса на всех кнопках при навигации с клавиатуры; меню и палитра управляются стрелками |
| Меньше движения по желанию | WCAG 2.2, 2.3.3; `prefers-reduced-motion` | Анимации отключаются системной настройкой |
| Эстетика и минимализм | Nielsen (№8) | Одна акцентная краска, тёплая нейтральная палитра, одна серия иконок (Lucide), системный шрифт без загрузки |

## Дизайн-система

Все значения — CSS-переменные в начале `app.css`; тёмная тема переопределяет только цвета.

- **Цвет.** Фон `--bg`, поверхности `--surface` / `--surface-2`, боковая панель `--sidebar`; текст `--fg`, `--fg-2`, `--muted`; линии `--line`, `--line-strong`; акцент `--accent` (кнопки) и `--accent-text` (ссылки, светлее в тёмной теме); статусы `--ok`, `--warn`, `--danger` и их `-soft` фоны; `--add` / `--del` для диффов.
- **Отступы.** Шаг 4 px: `--s-1` … `--s-8`.
- **Скругления.** `--r-xs` 6, `--r-sm` 8, `--r-md` 12, `--r-lg` 16, `--r-xl` 22 px.
- **Тени.** Три уровня: `--shadow-1` (карточки), `--shadow-2` (поле ввода), `--shadow-3` (меню, диалоги).
- **Движение.** `--fast` 120 мс для наведения, `--med` 200 мс для появления; кривая `--ease`.
- **Типографика.** Системный шрифт; засечки только для приветствия; моноширинный для кода, путей и команд. Размер текста меняется в настройках (`data-text` на `<html>`).
- **Цели касания.** `--tap`: 36 px с мышью, 44 px на сенсорном экране.

Компоненты: `.btn` (`primary`, `ghost`, `danger`, `sm`), `.icon-btn`, `.chip`, `.badge`, `.seg` (переключатель вариантов), `.switch`, `.input` / `.select` / `.textarea`, `.card`, меню `menu()`, диалог `dialog()`, уведомление `toast()`.

## Что агент и система умеют и где это в интерфейсе

| Возможность | Где |
|---|---|
| Размышления модели (сводки Codex, DeepSeek, мысли Gemini) | «Размышления» над ответом, событие `reasoning` |
| План `update_plan` | Карточка плана с прогрессом, обновляется на месте |
| Подтверждение команд и правок | Чип прав под полем ввода → «Спрашивать»; карточка с диффом и кнопками |
| Только чтение | Тот же чип, `--read-only` в терминале |
| Вопрос пользователю `ask_user` | Карточка с вариантами; ответ можно написать в поле ввода |
| Чтение страницы `web_fetch` | Шаг «Страница» |
| Субагенты `spawn_agent` | Шаги субагента вложены в его шаг |
| Другая модель провайдера, усилие размышления | Меню модели → «Модель»; чип «Усилие» для Codex / Responses |
| Рабочая папка чата | Чип машины → «Рабочая папка» или «Сделать рабочей» в файлах |
| Файлы на машине | Кнопка папки в шапке, Ctrl+Shift+E |
| Вложения | Скрепка, перетаскивание, вставка из буфера |
| Ветки, переименование, экспорт, поиск | Меню чата «⋯», поиск в боковой панели, палитра |
| Уведомления | Настройки → Интерфейс; в приложении для Android — системные уведомления |

## API хаба для интерфейса

- `GET /api/threads?q=` — чаты с полями `running`, `waiting`, `forked_from`, `snippet` (при поиске).
- `GET /api/threads/:name/meta`, `POST /api/threads/:name/title`, `POST /api/threads/:name/fork {upto}`.
- `POST /api/runs` принимает `mode` = `ui` (агент, который пишет интерфейс), `agent`, `chat`, `web`; API интерфейса и замков — в [face.md](face.md).
- `POST /api/runs` принимает ещё `access` (`full` / `ask` / `read`), `effort`, `cwd`, `interactive`.
- `POST /api/runs/:id/answer {ask, answer}` — ответ на подтверждение (`allow`, `allow_all`, `deny`, `deny: причина`) или вопрос.
- `POST /api/files {node, cwd, op, path, data}` — `list`, `read`, `write`, `mkdir`, `stat` на любой машине.
- `GET /raw/:token/:node/*path` — файл как веб-страница (HTML открывается с CSS и скриптами, в песочнице без доступа к хабу).

События рана (`/api/runs/:id/events`): `text`, `reasoning`, `tool_start` / `tool_end` (с `id` и `parent` для шагов субагента), `ask`, `answered`, `surface` (интерфейс задачи), `error`, `done`.
